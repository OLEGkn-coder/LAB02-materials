# Лабораторна робота №2: класифікація сміття за фото

Три моделі різної складності визначають матеріал предмета на фото: картон, скло, метал, папір, пластик або непридатне до переробки (набір TrashNet).

## Результати

Готові результати лежать у `results/`, запускати нічого не потрібно.

- `results/summary.md`: усі таблиці (у VS Code відкривається через Open Preview).
- `results/plots/`: графіки:
  - `accuracy.png`: точність трьох моделей;
  - `speed_vs_accuracy.png`: швидкість проти точності;
  - `cost.png`: час навчання, час на фото, параметри, розмір файлу;
  - `f1_by_class.png`: якість за кожним класом;
  - `confusion_random.png`, `confusion_block.png`: матриці помилок;
  - `agreement.png`: які моделі праві на кожному фото;
  - `training.png`: криві навчання;
  - `svm_grid.png`: підбір C і gamma для SVM;
  - `effnet_errors.png`: фото, на яких помилилась EfficientNet-B0.

| Модель          | Випадковий поділ | Поділ блоками |
| --------------- | ---------------- | ------------- |
| SVM на ознаках  | 73,1%            | 76,2%         |
| Власна CNN      | 74,7%            | 78,0%         |
| EfficientNet-B0 | 92,9%            | 93,1%         |

## Файли

| Файл                  | Що робить                                                                           |
| --------------------- | ----------------------------------------------------------------------------------- |
| `src/data.py`         | читання фото, вилучення дублікатів, поділ даних, збереження метрик                  |
| `src/svm_model.py`    | ознаки HSV, HOG, LBP і SVM                                                          |
| `src/nn_utils.py`     | спільне для нейромереж: дані, аугментації, цикл навчання                            |
| `src/cnn_model.py`    | власна згорткова мережа                                                             |
| `src/effnet_model.py` | донавчання EfficientNet-B0                                                          |
| `src/benchmark.py`    | час на одне фото і розмір файлів моделей                                            |
| `src/report.py`       | таблиці й графіки                                                   |
| `src/check_leak.py`   | перевірка схожості тестових фото на train                                           |
| `results/<поділ>/`    | метрики (`*.json`), моделі (`svm.pkl`, `cnn.pt`, `effnet.pt`), поділ (`split.json`) |
| `logs/`               | журнали навчання                                                                    |
